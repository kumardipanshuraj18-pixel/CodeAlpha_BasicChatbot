# CodeAlpha Basic Chatbot

## Project Overview
This project is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

The chatbot interacts with users through the terminal and provides predefined responses to different messages.

## Features
- Responds to greetings such as hello, hi, and hey.
- Answers the question "How are you?"
- Tells the user its name.
- Provides help when requested.
- Ends the conversation when the user types "bye".
- Handles unrecognized messages with a default response.

## Technologies Used
- Python 3

## Concepts Used
- Functions
- While loops
- Conditional statements
- User input and output
- String manipulation

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python chatbot.py
```

## Example

```text
You: hello
Bot: Hi! Nice to meet you!

You: how are you
Bot: I'm fine, thanks! How about you?

You: bye
Bot: Goodbye! Have a great day!
```
